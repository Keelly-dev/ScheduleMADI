# Расписание МАДИ

Расписание пар для студентов и преподавателей университета МАДИ

Удобное расписание пар для студентов и преподавателей с автоматической загрузкой информации с сайта МАДИ и разделением недель на "числитель" и "знаменатель".

Приложение доступно для Android и Windows. Источник данных — [сайт расписания МАДИ](https://raspisanie.madi.ru/).

[Google Play](https://play.google.com/store/apps/details?id=com.wildchair.schedulemadi) · [RuStore](https://www.rustore.ru/catalog/app/com.wildchair.schedulemadi) · [APK из GitHub](https://github.com/wildchair/ScheduleMADI/releases/latest)

[Сообщить об ошибке](https://github.com/wildchair/ScheduleMADI/issues) · [Лицензия MIT](LICENSE.txt)

## Возможности

- Поиск студенческой группы или преподавателя по началу названия или фамилии.
- Просмотр предметов, времени занятий, аудиторий и преподавателей.
- Разделение недель на "числитель" и "знаменатель".
- Переход к дате через календарь; переключение дней горизонтальными свайпами.
- Индикатор хода занятия, рассчитанный по текущему времени устройства.
- Просмотр расписания экзаменов, когда оно опубликовано на сайте МАДИ.
- Сохранение выбранной группы или преподавателя между запусками.

Для первоначальной загрузки данных нужен интернет. Если расписание экзаменов ещё не опубликовано, приложение показывает сообщение сайта о сроке его доступности.

## Установка и начало работы

### Android

1. Установите «Расписание МАДИ» из [Google Play](https://play.google.com/store/apps/details?id=com.wildchair.schedulemadi) или [RuStore](https://www.rustore.ru/catalog/app/com.wildchair.schedulemadi).
2. Запустите приложение и откройте вкладку **«Настройки»**.
3. В поле **«Группа или ФИО»** начните вводить название группы или фамилию преподавателя и выберите результат.
4. Вернитесь на вкладку **«Расписание»**. Дату можно выбрать в календаре над занятиями.

Для установки напрямую скачайте `com.wildchair.schedulemadi-Signed.apk` из [GitHub Releases](https://github.com/wildchair/ScheduleMADI/releases/latest).

### Windows

Windows-версию можно собрать и запустить из исходников через Visual Studio — инструкция ниже. В опубликованном релизе доступен Android APK.

## Технологии и платформы

Проект использует C#, XAML, .NET 10, .NET MAUI 10 и CommunityToolkit. Интерфейс разделён на представления и модели представлений; сетевые запросы и разбор расписания находятся в `Model/ParseMADI.cs`.

| Платформа | Целевая платформа проекта | Минимальная версия ОС |
| --- | --- | --- |
| Android | `net10.0-android36.0` | Android 9 и более поздние версии (API 28+) |
| Windows | `net10.0-windows10.0.26100.0` | Windows 10, сборка 19041 |

В проекте также есть файлы шаблона для iOS, Mac Catalyst и Tizen, но эти платформы не включены в текущие цели сборки.

## Подготовка окружения

Для разработки на Windows нужны:

- Visual Studio 2026 с рабочей нагрузкой **.NET Multi-platform App UI development** и компонентами Android и Windows.
- .NET SDK из [global.json](global.json): `10.0.401` или более новый патч ветки `10.0.4xx`.
- Android SDK с платформой API 36 и JDK из установки Visual Studio для сборки Android.
- Windows SDK `10.0.26100.0` для сборки Windows.

Компоненты устанавливаются через Visual Studio Installer. Подробности — в [инструкции Microsoft по установке .NET MAUI](https://learn.microsoft.com/dotnet/maui/get-started/installation?view=net-maui-10.0).

Проверить выбранный SDK и рабочие нагрузки можно из корня репозитория:

```shell
dotnet --version
dotnet workload list
```

Получите исходники:

```shell
git clone https://github.com/wildchair/ScheduleMADI.git
cd ScheduleMADI
```

Для отправки собственных изменений сначала создайте форк и клонируйте его вместо исходного репозитория.

## Запуск из Visual Studio

1. Откройте `ScheduleMADI.sln` и дождитесь восстановления NuGet-пакетов.
2. Назначьте **ScheduleMADI** запускаемым проектом; выберите конфигурацию **Debug**.
3. Выберите цель рядом с кнопкой запуска:
   - **Windows Machine** — для запуска на компьютере;
   - Android-эмулятор или физический телефон — для запуска Android-версии.
4. Для телефона включите отладку по USB и подтвердите на устройстве подключение к компьютеру.
5. Нажмите **F5**.

Если Visual Studio сообщает, что проект необходимо развернуть, включите **Deploy / «Развёртывание»** для `ScheduleMADI` в **Сборка → Диспетчер конфигураций**. Для проекта тестов развёртывание не требуется.

При предложении переустановить уже зарегистрированную Windows-версию учитывайте, что Visual Studio предупреждает об удалении её сохранённого состояния.

## Сборка из командной строки

Все команды ниже выполняются из корня репозитория. Для сборки приложения должны быть установлены соответствующие рабочие нагрузки и SDK платформы.

### Android Debug

```shell
dotnet build ScheduleMADI/ScheduleMADI.csproj -f net10.0-android36.0 -c Debug
```

### Windows Debug

Выполняется на Windows. Параметр `TargetFrameworks` ограничивает восстановление Windows-целью, чтобы RID `win-x64` не применялся к Android.

```shell
dotnet build ScheduleMADI/ScheduleMADI.csproj -f net10.0-windows10.0.26100.0 -p:TargetFrameworks=net10.0-windows10.0.26100.0 -r win-x64 -c Debug
```

### Android Release APK для ARM64

```shell
dotnet publish ScheduleMADI/ScheduleMADI.csproj -f net10.0-android36.0 -p:TargetFrameworks=net10.0-android36.0 -r android-arm64 -c Release -p:AndroidPackageFormats=apk -o artifacts/android
```

APK появится в `artifacts/android`. Эта команда предназначена для локальной проверки: для выпуска обновления существующего приложения нужна подпись ключом его издателя.

### Тесты

Тестовый проект можно запускать отдельно, без сборки MAUI-приложения:

```shell
dotnet test ScheduleMadi.Tests/ScheduleMadi.Tests.csproj -c Debug
```

Тесты проверяют выбор даты, переходы между неделями, границы календаря, смену группы и расчёт прогресса занятий. Работа жестов, загрузка данных и сохранение настроек дополнительно проверяются в запущенном приложении.

## Как помочь проекту

Ошибки и предложения можно описать в [Issues](https://github.com/wildchair/ScheduleMADI/issues). Для ошибки укажите платформу, версию приложения, шаги воспроизведения и ожидаемый результат. Если проблема связана с расписанием, добавьте группу или преподавателя и выбранную дату.

Для изменений кода:

1. Создайте форк репозитория и отдельную ветку для одной задачи.
2. Внесите изменения, сохраняя существующие архитектуру и стиль проекта.
3. Соберите затронутые платформы и запустите тесты.
4. Проверьте поиск группы и преподавателя, загрузку расписания, смену даты и повторный запуск приложения. Для Android отдельно проверьте запуск на устройстве или эмуляторе.
5. Откройте Pull Request в `wildchair/ScheduleMADI` и опишите изменения и выполненные проверки.

Не добавляйте в репозиторий ключи подписи, пароли и локальные настройки IDE. CI собирает проверочный APK для PR и форков без ключей издателя; выпуск подписанных релизов выполняется в исходном репозитории.
